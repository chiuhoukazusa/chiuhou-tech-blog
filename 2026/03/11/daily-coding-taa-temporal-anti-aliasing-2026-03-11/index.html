TAA 时域抗锯齿渲染器

今天实现了 TAA（Temporal Anti-Aliasing，时域抗锯齿）——现代游戏引擎（UE4/UE5、Unity HDRP、寒霜引擎等）中广泛采用的抗锯齿技术。TAA 通过累积多帧的历史信息来消除锯齿，相比 MSAA/SSAA 在性能上极具优势。

项目目标

用纯 C++ 实现一个完整的 TAA 渲染管线，包含：

  1. Halton 低差异序列 Jitter — 亚像素抖动采样
  2. 历史帧 EMA 累积 — 指数移动平均混合
  3. Variance Clipping 方差裁剪 — 防止鬼影（Ghosting）
  4. 与无 AA / SSAA 4x 的对比输出

四图对比

左上：No-AA（明显锯齿）| 右上：SSAA 4x（参考质量）| 左下：TAA + Variance Clipping | 右下：TAA 无 Variance Clipping（可见鬼影）

TAA 原理详解

1. Jitter 采样

TAA 的核心思路是在不同帧对同一像素使用不同的亚像素偏移（Jitter）进行采样，然后将多帧结果累积。

为什么用 Halton 而不是随机数？
Halton 序列是低差异序列（Low-Discrepancy Sequence），能确保采样点均匀分布在像素内，避免随机采样的聚簇现象。

2. 历史帧累积（EMA）

  • alpha 越小：历史权重越大，积累更多帧，效果更平滑，但响应慢
  • alpha 越大：当前帧权重大，响应快，但抗锯齿效果减弱

经过 N 帧累积后，等效于采集了大量亚像素样本的超采样！

3. Variance Clipping（防鬼影关键）

问题：当物体移动或场景变化时，历史帧中的颜色值与当前位置不匹配，导致鬼影（Ghosting）。

解决方案：将历史颜色裁剪到当前帧邻域的颜色分布范围内。

这样，如果历史颜色偏离当前邻域太远，就会被强制拉回来，消除鬼影。

4. 鬼影对比

No Variance Clip With Variance Clip
鬼影 ❌ 有残影 ✅ 无鬼影
抗锯齿 ✅ 有效 ✅ 更有效
稳定性 低 高

量化验证

TAA 在累积 16 帧后，质量已与 SSAA 4x 完全相当，但 TAA 只需每帧渲染 1 spp！

性能对比

方法 每帧采样数 质量 实时可行
No-AA 1 spp 差 ✅
SSAA 4x 4 spp 好 ❌
MSAA 4x ~2 spp 中 ⚠️
TAA 1 spp 好 ✅

这就是为什么现代游戏引擎几乎都采用 TAA——用时间换空间，以 1 spp 的代价获得接近 4-16 spp 的质量。

今日所得

  1. TAA 的本质是时间超采样：把 SSAA 的空间采样分摊到时间轴上
  2. Halton 序列比随机更好：均匀覆盖，收敛更快
  3. Variance Clipping 是 TAA 的灵魂：没有它，历史帧会产生严重鬼影
  4. EMA 的 alpha 选择很关键：通常 0.05~0.15，需要在收敛速度和稳定性间权衡
