Forward+ Rendering (前向+渲染)

项目目标

实现 Forward+ Rendering（Tiled Forward Rendering），这是现代游戏引擎（Frostbite、Unity HDRP、Unreal Engine）广泛使用的多光源渲染技术。

与传统前向渲染相比，Forward+ 通过 Tile-based 光源分类，将每个像素需要处理的光源数量从「全部 N 个」减少到「该 Tile 内相关的 k 个」，大幅提升多光源场景的渲染效率。

核心架构

Forward+ 渲染管线（三步走）

对比传统方案：

方案 每像素遍历光源数 适合场景
朴素前向渲染 全部 N 个 光源少（<10）
延迟渲染 全部 N 个（光照阶段） 不透明物体多
Forward+ 仅 Tile 内 k 个 多光源+透明物体

场景配置

  • 7 个球体：金色金属球（中心）、红色粗糙球、蓝色光泽球等
  • 地面 + 背景墙（三角形构成）
  • 31 个彩色点光源（随机位置、颜色、强度）
  • 摄像机：(0, 4, 12) 俯视场景

多个彩色点光源照亮场景，金色金属球受到多个光源的高光影响，整体色调丰富。

  • 第 0 行 = [r.x, r.y, r.z, -r·eye]（right 向量）
  • 第 1 行 = [u.x, u.y, u.z, -u·eye]（up 向量）
  • 第 2 行 = [-f.x, -f.y, -f.z, f·eye]（-forward 向量，注意符号）

技术总结

Forward+ 的优势：

  1. 支持大量动态点光源（数十到数百个）
  2. 与前向渲染兼容，完整支持透明物体
  3. 内存占用比延迟渲染低（不需要完整 MRT G-Buffer）
  4. Tile 大小（16×16）可调节，权衡剔除精度和 overhead

适用场景：现代游戏（大量动态光源 + 透明特效）
