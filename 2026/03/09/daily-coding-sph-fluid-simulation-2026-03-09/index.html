SPH Fluid Simulation — 流体模拟

今天实现了基于 Smoothed Particle Hydrodynamics (SPH) 方法的 2D 流体模拟。
SPH 是一种拉格朗日粒子方法，通过在每个粒子上对周围粒子加权求和来近似连续介质方程——
广泛用于游戏引擎、电影特效（如水花飞溅）和科学计算。

SPH 核心原理

SPH 方法的精髓在于三个核函数，每个核函数针对不同物理量的近似特性选取：

1. Poly6 核（密度计算）

$$W_{poly6}(r, h) = \frac{4}{\pi h^8}(h^2 - r^2)^3$$

特点：在 $r \to 0$ 时梯度为零（适合标量量密度），避免粒子重叠时出现奇异值。

2. Spiky 核梯度（压力力）

$$\nabla W_{spiky}(r, h) = \frac{-10}{\pi h^5} \frac{(h-r)^2}{r} \hat{r}$$

特点：在原点处梯度不为零，可以正确推开重叠粒子，防止聚集（clustering）现象。

3. Viscosity 核拉普拉斯（粘性力）

$$\nabla^2 W_{visc}(r, h) = \frac{40}{\pi h^5}(h - r)$$

特点：拉普拉斯值恒为正，保证粘性力始终是耗散的（不会注入能量）。

经验总结

参数调校是 SPH 的最大挑战：

  • 核函数的归一化常数与坐标系单位强耦合，REST_DENS 必须与实际核函数积分值匹配
  • GAS_CONST（气体刚度）过大会导致数值爆炸，过小则流体太压缩
  • DT 需满足 CFL 条件：$dt < h / v_{max}$
  • 限速（max_speed = 20）是防止数值不稳定的实用技巧

SPH 的经典缺陷：

  • O(N²) 复杂度（本实现为暴力遍历，生产级用 Grid/Octree 加速）
  • 边界处理简单（正式实现用 Ghost Particles 或 Boundary Force）
  • 压力振荡（WCSPH 特性，PCISPH/IISPH 可改善）
