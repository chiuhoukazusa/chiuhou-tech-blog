SSAO - Screen Space Ambient Occlusion

项目目标

实现**屏幕空间环境光遮蔽（SSAO）**算法——现代实时渲染管线中增强场景真实感的核心技术之一。SSAO 通过在屏幕空间内对每个像素周围进行半球采样，近似计算该点被周围几何体遮蔽的程度，从而模拟漫反射环境光被遮挡时产生的接触阴影和角落暗化效果。

本项目在纯 CPU + 软光栅化器上从零实现完整的 SSAO 管线，无需 GPU/OpenGL，完全掌控每个细节。

渲染管线设计

整个实现分为四个 Pass：

Pass 1: G-Buffer 生成

软光栅化渲染场景（球体、圆柱、长方体、地面、后墙），将每个像素的视空间位置和视空间法线写入 G-Buffer：

每个像素写入：

  • position[idx]：视空间 XYZ 位置
  • normal[idx]：视空间法线
  • albedo[idx]：漫反射颜色

Pass 2: SSAO 计算

对 G-Buffer 中每个有效像素：

  1. 获取旋转向量：从 4×4 噪声纹理（tile 重复）取一个随机旋转向量
  2. 构建 TBN 矩阵：以像素法线为 Z 轴，用旋转向量 Gram-Schmidt 正交化得到 TBN
  3. 半球采样：将预生成的 32 个采样核（切线空间半球）通过 TBN 变换到视空间
  4. 采样点重投影：将视空间采样点通过透视投影矩阵投影到屏幕坐标
  5. 深度比较：对比采样点的视空间 Z 与 G-Buffer 中对应像素的真实 Z
  6. 遮蔽积累：被遮蔽则加权累加，权重由 smoothstep 范围衰减控制

Pass 3: 模糊降噪

4×4 Box Blur 对原始 SSAO 图进行平滑，消除半球随机采样带来的噪点。

Pass 4: 最终合成

最终应用 ACES 色调映射 + Gamma 矫正输出。

技术总结

  1. SSAO 的核心是近似，不是精确：通过有限样本（32个）+ 随机旋转 + 模糊，以极低代价获得视觉上可信的遮蔽效果
  2. 视空间深度比较的优势：避免了使用 NDC 深度时的透视失真，结果更均匀
  3. Bias 的必要性：SSAO_BIAS = 0.05 防止表面自遮蔽产生的条纹伪影（Self-shadowing Artifacts）
  4. 噪声 + 模糊 = 低采样率的解决方案：少量样本（32）× 随机旋转 → 高频噪声 → 模糊 → 平滑结果，是实时渲染中的经典权衡
  5. G-Buffer 的重要性：SSAO 依赖屏幕空间法线和深度，G-Buffer 是整个管线的基础
